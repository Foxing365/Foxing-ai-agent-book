# 实验运行记录保留与恢复

本分支保留中英文书稿、配图、实验实现、依赖配置、测试、数据集和测试样例。
2026-10-19 清理了 40 组不再被当前书稿、说明或测试引用的旧试跑，共 815 个文件、约 254.7 MiB。

## 保留了什么

- `validation/latest.json` 等正式结果入口及其引用的完整证据包。
- 当前 README、实验状态表、章节台账或测试引用的结果，包括负结果和失败案例。
- 每种实验/提供商运行族的最新记录，以及体积很小的诊断摘要。
- 正式运行的原始回执、请求与响应、哈希清单、截图和对照结果；不改写结果或状态。
- 大型原始回执中的断点续跑来源也逐级保留；例如提示工程 v7 → v6 → v5 → v4 → v2 的来源链，因此保留这些轮次。
- 训练/评测数据、输入样例、模型相关配置，以及代码运行和测试所需的文件。

## 清理了什么

- 同一运行族中未被引用、已被较新结果取代的 dated run 目录。
- 主要包括记忆评测旧轮次、PPT 与视频编辑反复试跑。
- `.DS_Store`、Python 字节码、pytest 和网站预览缓存。

每个移除文件的路径、大小和 SHA-256，以及保留运行的理由，见
[机器可读清单](EXPERIMENT_RETENTION.json)。被移除运行中自动生成的代码、文档和媒体
属于历史运行产物，已随完整证据包归档；实验入口、实现与测试代码没有删除。

## 恢复历史记录

历史记录仍可从清理前的 Git 提交恢复，无需重跑收费 API：

```bash
# 将 PATH 替换成清单中需要恢复的单个文件或目录。
git restore --source=dbc046eb896ac4e39aa19c7774c8bf49583b89a6 -- PATH
```

本次还在仓库之外保存并逐文件校验了压缩归档，包含全部移除记录和清理前的工作区补丁。
恢复 Git 中的文件会重新显示为工作区改动；按需审核后提交。

## 后续运行

普通试跑输出应留在忽略的 `validation/`、`runs/` 或 `results/` 目录。
新增正式证据时先确认凭据已脱敏、结果可验证，再用 `git add -f PATH` 显式加入需要保留的文件。
Git 忽略规则不会阻止 OneDrive 同步；本次没有改写 Git 历史，首次完整克隆仍会下载历史对象。
